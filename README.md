# Braids Oasis Website

**Braids Oasis** is a modern, responsive web application for a premium braiding and protective styling salon based in Mfuleni, Cape Town. The platform provides clients with an immersive digital journey to explore trending protective styles, calculate accurate custom quotes, request personalized consultations, and seamlessly book appointments.

---

##  Features

### 1. Style & Service Showcase
- Comprehensive catalog of contemporary braiding styles (e.g., Knotless, French Curls, Twists, Marley Twists).
- Interactive categorization filters (All Styles, Braids, Twists, Protective Styles).
- Detailed care instructions and styling lifespans integrated into service cards.

### 2. Multi-Tier Booking & Enquiry Ecosystem
- **Appointment Booking:** Standard intake capturing preferred dates, structural styles, and targeted lengths.
- **Quote Calculator:** Comprehensive cost evaluations based on custom length variations (Shoulder, Mid-back, Lower-back, Waist length) and optional extension-supply pricing.
- **Community Program Intakes:** Built-in form routing for local Volunteer and Sponsorship opportunities.

### 3. Smart Search & UX
- Real-time search panel with dynamic popular tags (e.g., *Knotless Braids*, *Passion Twists*).
- Streamlined interface featuring modal galleries, quick-action selectors, and a persistent operational footer.
- Comprehensive business logistics overlay detailing location information, lift access variables, and free street parking.

##  Technical Implementation

- **Semantic HTML5:** Built using SEO-friendly modular markup structures.
- **Custom CSS3 Variables:** Utilizes a centrally-managed `:root` variable grid for instant global theme swapping.
- **Fluid Layouts:** Uses custom Flexbox clusters and CSS Grids (`repeat(auto-fill, minmax(250px, 1fr))`) to guarantee responsive layout consistency from mobile displays up to 4K monitors.
- **Micro-interactions:** Configured with active-state translations (`translateY(-2px)`) and backdrop filters to enrich user navigation feedback loop.

##  Getting Started

### Prerequisites
A modern web browser (Chrome, Firefox, Safari, Edge).

### Installation & Local Development
1. Clone the repository to your local directory:
   ```bash
   git clone https://github.com
   ```
2. Navigate into the project folder:
   ```bash
   cd braids-oasis
   ```
3. Open `index.html` directly in your browser, or spin up a local development server using a code editor extension (such as VS Code's *Live Server*).
